# Free NIFTY Candle Scanner V5

Latest uploaded V5 project baseline.

## Run

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

The runtime `data/` directory and local `.venv/` are intentionally not committed. Do not commit local authentication/session secrets.
